# Titanic Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The objective is to understand the dataset by exploring its structure, identifying missing values, analyzing statistical summaries, and visualizing relationships between variables.

---

## 📂 Dataset
- **Dataset:** Titanic Dataset
- **Source:** Kaggle
- **File:** Titanic-Dataset.csv

---

## 🛠️ Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 Exploratory Data Analysis Performed
- Data Loading
- Dataset Information (`info()`)
- Statistical Summary (`describe()`)
- Missing Value Analysis
- Duplicate Value Check
- Value Counts
- Histogram
- Boxplot
- Scatter Plot
- Correlation Heatmap
- Pairplot

---

## 📈 Key Findings
- The dataset contains **891 passengers** and **12 columns**.
- Missing values were found in the **Age**, **Cabin**, and **Embarked** columns.
- Most passengers were between **20 and 40 years** of age.
- The majority of passengers traveled in **Third Class**.
- Female passengers had a higher survival rate than male passengers.
- Passengers who paid higher fares generally had a higher chance of survival.
- The **Fare** column contains several outliers.
- Most numerical variables showed weak correlations, while **Fare** and **Pclass** had a noticeable relationship.
